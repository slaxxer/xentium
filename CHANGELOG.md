# Changelog

## i18n: Style Editor translated (part 3)

- The **Style Editor** admin page — the largest, most string-dense page — is now
  translated across all five bundled locales: section navigation, mode/scope/preview-state
  controls, palette/text/feedback row names, branding and custom-CSS panels, the live
  preview toolbar, confirmations, toasts, and hints.
- The deeply technical per-token labels that come from the shared token registry
  (`@nodevo/contracts`) remain in English for now — those are a separate, registry-level
  translation pass.
