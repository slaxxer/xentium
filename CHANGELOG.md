# Changelog

## Licence keys read XEN

### Changed

- **Every generated reference carries the `XEN-` prefix.** Licence keys and their
  display references, order references and connect codes were still minted `NDV-`,
  which was the old brand's initials on the one string a customer reads aloud to
  support.
- Invite codes follow: `NDVO-…` becomes `XEN-INV-…`.

### Notes

- Forward-only, and safe. Nothing anywhere validates the prefix — it is a label,
  not a format — so references already issued keep working exactly as they are.
